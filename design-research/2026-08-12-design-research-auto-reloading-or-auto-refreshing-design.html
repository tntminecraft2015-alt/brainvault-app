Real-Time Revision Delivery: Auto-Reload & Live Refresh for Design Lab Slideshows

Research surfaces three patterns for keeping design research slideshows live without manual reopen: event-driven polling (similar to how dashboard monitoring works), graceful fade-and-replace transitions (inspired by modern carousel design), and a pause-on-interact mechanic borrowed from real-time financial dashboards. Each pattern respects the JRPG aesthetic while reducing friction between Red's rework and user review.

3 findings · focus: auto-reloading or auto-refreshing design revisions in the Design Lab slideshow when Red finishes reworking a rated idea, so the user does not have to manually reopen it

FINDING 1 / 3

Event-Driven Soft Refresh with Connection Status Badge

Detect when data arrives and trigger a refresh only when needed, rather than constant polling. When Red finishes a revision, the server emits a lightweight event; the client polls short intervals only while the slideshow modal is open. A small "●" badge in the modal header animates to signal the refresh is live, never blocking the user's view of the current slide. Pairs well with Mission Control's retro aesthetic via simple dot/pulse animations in the accent color.

Source: Microsoft Fabric Real-Time Dashboards

FINDING 2 / 3

Seamless Fade-and-Replace Slide Transition on Revision

While one box shrinks and gets ready to leave, the next box enters the scene, creating a constant loop of boxes entering and exiting continuously. When a revision loads, fade out the old finding card (200ms) and fade in the new one from behind it. The mockup itself (the HTML sandbox iframe) cross-fades instead of hard-reloading, preserving scroll position if the user is mid-read. Feels alive without breaking JRPG aesthetic; uses Mission Control's accent/green palette for the fade pulse.

Source: Animated Slideshow Carousel Transitions

FINDING 3 / 3

Pause-on-Interact with Manual Refresh Fallback

Provide flexibility: if you're investigating a specific data point and don't want visuals to change, pause live refresh. While paused, no automated refreshes occur; when ready, resume to return to real-time monitoring. A small pause button (⏸) in the slideshow footer stops incoming revisions mid-read; tapping resume or navigating to the next finding auto-restarts polling. Prevents frustration when user is comparing the old mockup to feedback notes. Low-friction, respects user agency—very on-brand for a personal dashboard.

Source: Microsoft Fabric Live Refresh Controls
